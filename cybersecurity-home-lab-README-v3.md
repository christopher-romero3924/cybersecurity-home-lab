# Cybersecurity Home Lab

A virtualized enterprise network environment built for hands-on practice in threat detection, network security monitoring, SIEM operations, penetration testing fundamentals, and offensive security awareness.

All machines run simultaneously on a single physical host using VirtualBox — simulating a real enterprise environment including domain infrastructure, vulnerable targets, monitoring systems, and an attacker machine.

---

## Lab Overview

**Hypervisor:** Oracle VirtualBox  
**Host OS:** Windows  
**Total VMs:** 8  
**Network Design:** Segmented internal network — corporate zone, monitoring zone, and attacker zone

---

## Tools & Technologies

### Security Monitoring & SIEM
- **Security Onion** — Network security monitoring, intrusion detection (Suricata/Zeek), full packet capture, alert review
- **Splunk** — Log ingestion from Windows and Linux endpoints, SPL search queries, correlation rules, dashboard creation, SOC Tier 1 alert triage workflows

### Penetration Testing & Offensive Security
- **Kali Linux** — Full penetration testing distribution used as the primary attack machine
- **Metasploit Framework** — Exploitation framework used against Metasploitable and Vuln 1 targets
- **Nmap** — Host discovery, port scanning, service enumeration, OS fingerprinting
- **Metasploitable** — Deliberately vulnerable Linux VM providing a safe, legal target for exploitation practice

### Infrastructure
- **Windows Server / Active Directory (DC1)** — Domain controller, user provisioning, group policy, OU structure, access control
- **Windows 10 Workstations** — Domain-joined clients generating realistic Windows Event Logs forwarded to Splunk
- **Vulnerable Windows 10 (Vuln 1)** — Intentionally misconfigured Windows target for practicing Windows-based attack and detection scenarios

## Lab Projects & Exercises

### Project 1 — Active Directory Domain Build
Deployed DC1 as a Windows Server domain controller. Configured Active Directory Domain Services, created organizational units, user accounts, and group policies. Joined Client 1 and Client 2 as domain workstations. Practiced user provisioning, password policy enforcement, and least-privilege access control.

**Skills:** Active Directory, Windows Server, Group Policy, Domain Administration, Access Control

---

### Project 2 — Security Onion IDS Deployment
Deployed Security Onion in monitoring mode across the lab network. Configured Suricata for signature-based intrusion detection and Zeek for network protocol analysis. Reviewed and triaged alerts generated by simulated attack traffic originating from Kali Linux.

**Skills:** Security Onion, Suricata, Zeek, IDS, Network Security Monitoring, Alert Triage

---

### Project 3 — Splunk SIEM Configuration (In Progress)
Deployed Splunk on a dedicated server VM. Configured Universal Forwarders on Windows endpoints (DC1, Client 1, Client 2) to forward Windows Event Logs to Splunk. Building SPL search queries and beginning correlation rule development to simulate SOC Tier 1 alert triage workflows.

**Skills:** Splunk, SIEM, Log Aggregation, SPL, Windows Event Logs, Forwarder Configuration

---

### Project 4 — Metasploitable Exploitation & Detection
Used Kali Linux and Metasploit Framework to exploit known vulnerabilities on the Metasploitable target. Simultaneously monitored Security Onion for IDS alerts generated by the attack traffic. Correlated offensive actions with defensive detections — building the attacker-to-defender perspective critical for SOC analysis.

**Skills:** Metasploit, Kali Linux, Exploitation, IDS Alert Analysis, Attack-Defense Correlation

---

### Project 5 — Network Reconnaissance with Nmap
Conducted structured reconnaissance exercises across all lab targets using Nmap. Performed host discovery sweeps, TCP/UDP port scans, service version detection, and OS fingerprinting. Documented findings in structured scan reports and observed corresponding Security Onion alerts generated by the scans.

**Skills:** Nmap, Network Reconnaissance, Port Scanning, Service Enumeration, Detection Correlation
